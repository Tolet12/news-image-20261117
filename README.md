This program writes a one-image summary of 17 November 2026 world news: a newspaper front page drawn entirely in code. Its four panels show the collapsed Crimean Bridge, tankers mined at Hormuz, Trump in Manila, and the lost Vulcan rocket, with a ticker strip along the bottom carrying the day's other stories. The graded program (`main.py`, Python standard library only) copies the committed `entry.png` to the output directory; the image itself was drawn locally by `make_image.py` using Pillow.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
